Your results are remembered in this browser automatically. Use “Save a copy” to keep them inside the file itself (replace this file with the downloaded copy).

1. Get ready

  1. Open a terminal in C:\Users\Admin\Sunil\Trading.
  2. Build the web app (about a minute): 
    pnpm --filter @trading/app export:web
  3. Start the app and the data helper: 
    pnpm uat:start
    Leave this terminal open; Ctrl+C stops both. It uses ports 8080 and 8787.
  4. Open Chrome at http://127.0.0.1:8080. Case A1 uses your normal window (it holds your data from earlier rounds); most other laptop cases use a new private window (Ctrl+Shift+N), which behaves like a new device. Keep one private window open from A2 to E1, because C, D and E build on it.
  5. For section G you need the Android phone, a way to move files between the laptop and the phone (USB cable, Google Drive, or a message to yourself), and the APK at packages\app\build-apk\market-learning-0.1.0-preview-arm64.apk.

2. Pass bar

  • Every case marked Must passes.
  • No practice data is lost: not on upgrade, not on a refused import, not when the app is closed.
  • No astrology anywhere in the app.
  • A backup file never holds a PIN or the signing key.
  • E4 and E5 are exploratory: they do not block.

“Automated” means the same check passed on 2026-10-26 when this page was prepared. You are confirming it with your own eyes.
