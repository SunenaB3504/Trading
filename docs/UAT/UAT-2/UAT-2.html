Scope: the changes made after round 1 (the polish list) and the new optional layer (Profile and the two personal shields), using the demo data that exists today. Tester: Sunil, on the local laptop. Prepared 2026-10-19 from commit 734ad62. Round 1 is recorded in docs/UAT/UAT-1. Virtual money only.

Your results are remembered in this browser automatically. Use “Save a copy” to keep them inside the file itself (replace this file with the downloaded copy).

1. Get ready

  1. Open a terminal in C:\Users\Admin\Sunil\Trading.
  2. The app changed since round 1, so build it again (about a minute): 
    pnpm --filter @trading/app export:web
  3. Start the app and the data service: 
    pnpm uat:start
    Leave the terminal open; Ctrl+C stops both. (Opening http://127.0.0.1:8787 shows no such endpoint /; that is normal, the service has no page.)
  4. Open http://127.0.0.1:8080 in a private window so no earlier data interferes. Use Chrome or Edge.
  5. Starting clean. Several cases need an empty book. To empty everything: press F12, open Application, choose Storage, press Clear site data, then reload. Do this before section A, and again before B1.
  6. The optional layer is switched off by default. It appears only after you open the app once at http://127.0.0.1:8080/?layer=on. ?layer=off switches it off again. The setting is remembered on this device.

The demo data is fixed, so the numbers you see should match the expected results below, except where a case says the answer depends on today's date. If a number differs, mark the case Fail and write what you saw in the note.
