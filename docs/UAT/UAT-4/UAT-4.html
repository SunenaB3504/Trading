Scope: the lots popup on the Ledger (WP-3.12), Edit my birth details (WP-4.12) and the Hindi language (WP-4.11), plus the round 3 cases that were skipped. Tester: Sunil, on the local laptop. Prepared 2026-10-19 against the build of that date.

Your results are remembered in this browser automatically. Use “Save a copy” to keep them inside the file itself (replace this file with the downloaded copy).

1. Get ready

  1. Open a terminal in C:\Users\Admin\Sunil\Trading.
  2. The app changed again (new fonts and languages), so build it once more (about a minute): 
    pnpm --filter @trading/app export:web
  3. Start the app and the data service: 
    pnpm uat:start
    Leave the terminal open; Ctrl+C stops both.
  4. Open a new private window (Ctrl+Shift+N) at http://127.0.0.1:8080/?layer=on. A private window starts with no stored data, which several cases need. Use Chrome or Edge.
  5. Starting clean again. If a case says to start clean: close every private window and open a new one. (Clearing site data from DevTools did not always empty the book in round 2.)
  6. Test birth. Section A and B use this invented birth, so the expected values below apply: Name Test Person, date 1975-08-15, time 10:30, place Mumbai, IN (the first suggestion for “Mumbai”, not Navi Mumbai).

The expected chart values come from Swiss Ephemeris and the IANA time-zone database, not from the app's own code. The running daśā and bhukti depend on today's date; the page says which dates the expected values hold for.

2. Pass bar

  • Every case marked Must passes.
  • No open defect that loses or corrupts data, or shows a wrong chart fact in either language.
  • A locked device (no ?layer=on, never switched on) shows and downloads nothing of the layer: no Profile tab, no astro word, no font file.
  • Birth details, gender and star are never readable in storage and are gone with their key after Delete.
  • B13 (reading the Malayalam text) is exploratory: it does not block, and your corrections go into the next draft.

“Automated” means the same check already passed in an automated browser run on 2026-10-19 (pnpm e2e:*). You are confirming it with your own eyes.
