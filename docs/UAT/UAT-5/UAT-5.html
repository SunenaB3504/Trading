User acceptance test 5: daily snapshot and the R2 report

Scope: the daily snapshot download on the Data tab with the host on your own laptop (WP-3.9, D26) and the first frozen H-21 run with its R2 report (WP-5.6). Tester: Sunil, on the local laptop. Prepared 2026-10-23 against the build of that date. Round 4 is still open (21 of 23 cases: lots popup, Edit birth details, Hindi, and the round 3 cases you skipped); this round does not repeat them.

Your results are remembered in this browser automatically. Use “Save a copy” to keep them inside the file itself (replace this file with the downloaded copy).

1. Get ready

  1. Open a terminal in C:\Users\Admin\Sunil\Trading.
  2. The app’s snapshot settings changed (host address and key), so build it once more (about a minute): 
    pnpm --filter @trading/app export:web
  3. Start the app and the market-data service: 
    pnpm uat:start
    Leave this terminal open; Ctrl+C stops both. It uses ports 8080 and 8787.
  4. The snapshot host is a second terminal that the cases start and stop themselves (port 8788, so it does not clash with 8787). The signing key is the one made for D26: C:\Users\Admin\keys\snapshot_k1.pem. Never open or paste its contents.
  5. Use a new private window (Ctrl+Shift+N) at http://127.0.0.1:8080 for every Section A case; a private window starts with no stored snapshot. Chrome or Edge.
  6. Wherever a case says YYYY-MM-DD use today’s date in India; on a weekend or exchange holiday use the last trading day. YYYYMMDD is the same date without dashes.

2. Pass bar

  • Every case marked Must passes.
  • A bad, tampered, older or unreachable snapshot never replaces or removes a good stored one.
  • The only network traffic from the snapshot button is GET requests for base_tickets_YYYYMMDD.json on 127.0.0.1:8788: nothing about you or your trades is sent.
  • The public snapshot file has no astro field.
  • B3 and B4 are exploratory: they do not block, and your corrections go into the next draft.

“Automated” means the same check passed on 2026-10-23 when this page was prepared. You are confirming it with your own eyes.
