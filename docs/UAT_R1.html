User acceptance test: web app, release 1.5 build

Scope: the web app with the data that exists today (a 16-name demo universe and a demo ledger). Tester: Sunil, on the local laptop. Prepared 2026-10-18. Build: commit 0b7e10c plus the UAT launcher. Virtual money only.

Your results are remembered in this browser automatically. Use “Save a copy” to keep them inside the file itself (replace this file with the downloaded copy).

1. Get ready

  1. Open a terminal in C:\Users\Admin\Sunil\Trading.
  2. Build the web app once (about a minute): 
    pnpm --filter @trading/app export:web
  3. Start the app and the data service: 
    pnpm uat:start
    It prints App: http://127.0.0.1:8080 and Service: http://127.0.0.1:8787. Leave the terminal open; Ctrl+C stops both. The service on 8787 has no web page: opening it shows no such endpoint /, which is normal. To check it is alive open http://127.0.0.1:8787/health and look for "status":"ok".
  4. Open http://127.0.0.1:8080 in Chrome. Use a fresh profile or a private window for the first run so no earlier data interferes.

The demo data is fixed, so the numbers you see should match the expected results below. If a number differs, mark the case Fail and put what you saw in the note.
